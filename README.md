# Lost & Found - Minimal Flask App

This repository contains a minimal Flask-based Lost & Found web app implementing the features described in `Requirements.txt`.

Quick start

1. Create a Python venv and install dependencies:

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install -r web-requirements.txt
```

2. Run the app:

```powershell
python app.py
```

Open http://127.0.0.1:5000
